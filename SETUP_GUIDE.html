Relationship Games: setup guide

Grade 11 · Unit 4 · Week 10 · Session 2 · Table Relationships · Slides 15–27. Two live games and the Relationships Lab: Split the Sheet! (warm-up) and Link Up! (wrap-up).

Firebase is already set up and config.js is already filled in. Just do step 1: create a new repository called G11W10S2 and upload these files. Scores for these games are kept separate from all your other games.

In these games
  • Mystery topic in the warm-up: every right answer flips three letters of TABLE RELATIONSHIPS.
  • Sort-into-groups cards: customer vs order columns, and 1:1 / 1:M / M:M pairs.
  • Order the tiles (split a big sheet, build a many-to-many link) and tap the SQL line that creates the foreign key.
  • 🔥 Streak bonus, 3-2-1-GO countdown, live moves feed, class accuracy and auto-results on your board.
  • Relationships Lab (lab.html): students spot repeated data, split a big table, classify 1:1, 1:M and M:M links, connect tables with foreign keys, build a junction table and run a JOIN. Live missions, a progress bar, Show me demos and a certificate when they reach 100%. Works on phones too.

1Put the games on GitHub Pages

  1. On github.com click New repository. Name it exactly G11W10S2, set it to Public, and create it.
  2. Click uploading an existing file. Drag in all the files from this folder (not the folder itself). Click Commit changes.
  3. Open Settings → Pages. Under Build and deployment choose Deploy from a branch, branch main, folder / (root), and click Save.
  4. Wait 1–2 minutes and refresh. The games are now at https://emanjeha.github.io/G11W10S2/
  5. If you use a different repository name, open config.js and change SITE_URL to match. (The lesson page also uses this address for its QR codes.)

3Run it in class

Classroom screenOpen https://emanjeha.github.io/G11W10S2/board.html?game=warmup on the classroom computer and press Full screen on the projector or smart board. The QR code and join link appear on the left.
StudentsOne device each (or one per pair). They scan the QR code or open the link, type their name and press Join.
StartPress Start game. Everyone sees 3-2-1-GO, then the questions. The board re-ranks live and shows each move in the Live moves feed.
EndResults open by themselves when everyone finishes. Or press End game to stop and show the podium and the hardest questions.
Wrap-upPress Switch to Link Up!. After it ends, press Show answers to read every exit ticket.
Next classPress New round (click twice). This clears the board for a fresh group.

4Good to know

  • Practice mode: without internet access to Firebase, students can still play, but nothing appears on the board.
  • Refreshing is safe: if a page reloads, the student continues where they were .
  • Late players can join at any time while the game is live.
  • Scoring: 100 points per correct answer, up to 50 for speed, and a streak bonus (+20, +40, +60) from the 3rd right answer in a row. In the warm-up, cracking the mystery topic is worth +200.
  • Keyboard: on a laptop, students can answer multiple-choice with keys 1–4 or A–D and press Enter for the next question.
  • Changing questions: edit questions.js in GitHub (pencil icon) and commit. The top of that file explains each question type.
  • Who can control the board: anyone who opens board.html can press Start or End, so don't share that link with students.

5If you ever need a new Firebase

  1. Go to console.firebase.google.com, create a project, then Build → Realtime Database → Create Database (location europe-west1), test mode.
  2. In Rules, paste {"rules":{"sessions":{".read":true,".write":true}}} and click Publish.
  3. In Project settings → Your apps → </>, register a web app and copy the values into config.js.
